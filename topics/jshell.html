JShell — The Java REPL Java 9

JShell (JEP 222) is Java's official interactive Read-Eval-Print Loop. It lets you evaluate declarations, statements, and expressions directly without the boilerplate of a class or main method, making it an essential tool for prototyping, learning, and debugging.

The problem it solves Before Java 9, testing a one-line Java expression required creating a file, writing a class, adding a public static void main, compiling it, and running it. JShell removes this friction, bringing Java in line with languages like Python or Node.js that have native interactive shells.

1 · Basic Usage & Shortcuts

To start JShell, simply type jshell in your terminal. You can immediately type expressions, statements, or declarations.

jshell> 10 + 25
$1 ==> 35
|  created scratch variable $1 : int

jshell> Math.sqrt($1)
$2 ==> 5.916079783099616

Essential Shortcuts

ShortcutAction
TabAutocompletes identifiers, methods, and classes. Press twice inside a method call (e.g., Math.max() to see overloads, and thrice for Javadoc.
Shift+Tab then vExtract Variable: Converts the expression into a strongly-typed variable declaration automatically.
Shift+Tab then iAuto-Import: Finds and imports unresolved classes based on what you've typed.
Ctrl+RReverse search through your command history.

2 · Slash Commands

JShell commands start with a forward slash (/) and control the environment state. They can be abbreviated (e.g., /v for /vars).

CommandDescription
/vars, /methods, /typesLists active variables, methods, or classes/interfaces/records defined in your session.
/importsLists all active imports.
/listShows all snippets you've entered with their IDs (e.g., 1, 2).
/edit [id]Opens the specified snippet (or all active snippets) in an editor.
/drop [id]Deletes a variable, method, or class from the session state.
/save <file>Saves the current session history or active snippets to a local file.
/open <file>Executes a JShell script file or built-in script (like PRINTING).
/envModifies the classpath or module path dynamically, triggering a reset and replay.
/resetWipes the session slate clean.
/historyDisplays the full history of all code snippets and slash commands typed.

3 · Advanced Features

Forward References (Corralled Snippets)

JShell supports declaring a method that references an undefined method or variable. JShell will accept it (marking it "recoverable"), but execution will fail until the missing dependency is declared.

jshell> double getVolume() { return height * calcArea(); }
|  created method getVolume(), however, it cannot be invoked until variable height, and method calcArea() are declared

jshell> double height = 10.0;
jshell> double calcArea() { return 25.0; }
jshell> getVolume()
$3 ==> 250.0
Note: Forward referencing works for methods and classes, but not for variable initializers (e.g., int x = y + 1; will fail if y doesn't exist).

External Editors

The built-in prompt is great for one-liners, but multi-line methods are easier in an editor. You can configure JShell to open your preferred IDE or terminal editor when you run /edit:

# For VS Code (use --wait so JShell halts until you close the file)
jshell> /set editor -retain "code --wait"

# For Vim or Nano
jshell> /set editor -retain vim

Custom Feedback Modes

If you find JShell too noisy, you can reduce its output verbosity using feedback modes: normal (default), verbose, concise, or silent.

# Switch to concise mode
jshell> /set feedback concise

# Retain this choice across all future terminal sessions
jshell> /set feedback -retain concise

Startup Scripts and Classpaths

By default, JShell imports java.util.*, java.io.*, etc. You can load additional built-in scripts, like PRINTING, to skip writing System.out. every time:

jshell> /set start -retain DEFAULT PRINTING
jshell> println("Hello without System.out!")

To launch JShell with external JARs or modules, pass them at startup:

$ jshell --class-path "libs/*:target/classes"

Or modify it mid-session:

jshell> /env --class-path /libs/gson-2.10.1.jar
