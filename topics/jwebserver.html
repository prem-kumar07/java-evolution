Simple Web Server (jwebserver) Java 18

Introduced in Java 18 (JEP 408), the Simple Web Server is a lightweight, out-of-the-box HTTP server for serving static files. It removes the need for Python, Node, or Apache just to preview local assets during development or education.

CLIstart from terminal
APIprogrammatic hooks
Staticfiles only (GET / HEAD)
Java 18introduction

1 · Command-Line Tool

To serve the current directory on port 8000, simply run jwebserver.

$ jwebserver
Binding to 127.0.0.1:8000 and serving /Users/you/project
URL http://127.0.0.1:8000/

You can customize the directory, port, and binding address (e.g., to make it accessible to your local network instead of just localhost):

$ jwebserver -b 0.0.0.0 -p 9000 -d ./public -o verbose

2 · Programmatic API

If you want to bake the static file server into your application, Java 18 added factory methods to com.sun.net.httpserver.SimpleFileServer and HttpHandlers.

Basic Embedded Server

import com.sun.net.httpserver.*;
import java.net.InetSocketAddress;
import java.nio.file.Path;

public class BasicFileServer {
    public static void main(String[] args) {
        var address = new InetSocketAddress(8080);
        var rootDir = Path.of("./public").toAbsolutePath();
        
        HttpServer server = SimpleFileServer.createFileServer(address, rootDir, SimpleFileServer.OutputLevel.INFO);
        server.start();
        
        System.out.println("Serving on http://localhost:8080");
    }
}

Advanced Routing & Fallbacks

You can compose handlers conditionally. For example, serve static files for public paths, but return a custom 403 response for hidden paths.

import com.sun.net.httpserver.*;
import java.net.InetSocketAddress;
import java.nio.file.Path;

public class AdvancedRoutingServer {
    public static void main(String[] args) throws Exception {
        var staticDir = Path.of("./static").toAbsolutePath();
        HttpHandler fileHandler = SimpleFileServer.createFileHandler(staticDir);

        // Fallback for forbidden access
        HttpHandler forbidden = HttpHandlers.of(403, new Headers(), "Access Denied");

        // Route traffic conditionally
        HttpHandler router = HttpHandlers.handleOrElse(
            req -> !req.getRequestURI().getPath().startsWith("/admin"),
            fileHandler,
            forbidden
        );

        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0, "/", router);
        server.start();
    }
}
