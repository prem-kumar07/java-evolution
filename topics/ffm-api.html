Foreign Function & Memory API Final in Java 22

The FFM API lets pure Java call native (C) functions and manage off-heap memory safely, with no hand-written C glue. It's the modern, supported replacement for JNI and the sun.misc.Unsafe memory tricks.

The problem it solves Talking to native code meant JNI — hand-written C, compiled per platform, easy to crash the JVM — and off-heap memory meant the unsafe, leak-prone sun.misc.Unsafe. FFM replaces both with a typed, bounds-checked, pure-Java API where memory has an explicit, deterministic lifetime.

3 · Off-heap memory: Arena & MemorySegment

Legacy — ByteBuffer / Unsafe
ByteBuffer buf = ByteBuffer.allocateDirect(16)
    .order(ByteOrder.nativeOrder());
buf.putInt(0, 42);
int v = buf.getInt(0);
// no explicit lifetime; freed whenever the GC/cleaner gets to it
Arena + MemorySegment
try (Arena arena = Arena.ofConfined()) {
  MemorySegment seg = arena.allocate(ValueLayout.JAVA_INT, 4);
  seg.setAtIndex(ValueLayout.JAVA_INT, 0, 42);
  int v = seg.getAtIndex(ValueLayout.JAVA_INT, 0);
}   // memory released deterministically here

Arena controls lifetime & sharing: ofConfined() (one thread, cheapest), ofShared() (many threads), ofAuto() (GC-managed), global() (never freed). Access after an arena closes throws instead of corrupting memory.

4 · Calling native functions

// call C's  size_t strlen(const char *s);
Linker linker = Linker.nativeLinker();
SymbolLookup std = linker.defaultLookup();

MethodHandle strlen = linker.downcallHandle(
    std.find("strlen").orElseThrow(),
    FunctionDescriptor.of(ValueLayout.JAVA_LONG,     // return: size_t
                          ValueLayout.ADDRESS));     // arg: char*

try (Arena arena = Arena.ofConfined()) {
  MemorySegment cString = arena.allocateUtf8String("hello");
  long len = (long) strlen.invoke(cString);          // → 5
}

5 · Upcalls — pass a Java method as a C callback

// turn a Java method into a native function pointer (e.g. qsort's comparator)
MethodHandle cmp = MethodHandles.lookup().findStatic(
    MyCmp.class, "compare",
    MethodType.methodType(int.class, MemorySegment.class, MemorySegment.class));
MemorySegment cmpPtr = linker.upcallStub(cmp,
    FunctionDescriptor.of(JAVA_INT, ADDRESS, ADDRESS), arena);

6 · jextract — generate bindings automatically

For real libraries you rarely hand-write handles. The jextract tool reads a C header and generates ready-to-use Java bindings:

jextract --output src -t org.example.zlib -l z /usr/include/zlib.h
// then call generated methods like  zlib.compress(...)

7 · Native-access restrictions

Because native calls can crash the VM, they're a restricted operation. Enable them explicitly:

java --enable-native-access=com.myapp   -jar app.jar   # a module
java --enable-native-access=ALL-UNNAMED -jar app.jar   # classpath apps
// without it you get warnings now, errors later

8 · Pitfalls

PitfallReality
Missing --enable-native-accessNative calls warn/fail — grant it to the calling module.
Sharing a confined segment across threadsThrows — use Arena.ofShared().
Wrong ValueLayout / alignmentMust match the C ABI exactly (size, alignment, endianness) — mismatches corrupt data. Prefer jextract.
Use-after-closeTouching a segment after its arena closes throws (by design) — scope with try-with-resources.
Off-heap memory & the GCOff-heap memory isn't heap — the Arena is its lifetime, not the GC.

Worked example — read a large file off-heap without copying to the heap

Legacy — ByteBuffer, awkward lifetime
try (var ch = FileChannel.open(path)) {
  MappedByteBuffer buf = ch.map(READ_ONLY, 0, ch.size());
  byte b = buf.get(1_000_000);
  // buffer stays mapped until GC frees it — no explicit close
}
FFM — mapped segment with a scoped Arena
try (Arena arena = Arena.ofConfined();
     var ch = FileChannel.open(path)) {
  MemorySegment seg = ch.map(READ_ONLY, 0, ch.size(), arena);
  byte b = seg.get(ValueLayout.JAVA_BYTE, 1_000_000);
}   // unmapped deterministically here

10 · Cheat sheet

FFM in one glance

  • Memory: try (Arena a = Arena.ofConfined()) { a.allocate(...); } — deterministic free.
  • Call C: Linker.nativeLinker().downcallHandle(symbol, FunctionDescriptor).
  • Callbacks: linker.upcallStub(...).
  • Generate bindings with jextract; match the C ABI via ValueLayout.
  • Grant --enable-native-access. Replaces JNI + Unsafe.
