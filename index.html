Java Evolution

Every Java feature, version by version, from Java 8 onward — organised by language features, new APIs, tooling and JVM/other changes, with tiny before → after snippets so you can see the old way and the new way side by side.

8 9 11 17 21 25 26 →
How the versions work. Java ships every 6 months, but only some releases are LTS (long-term support, filled above). This guide has a page for each major stepping-stone release and folds the features of the in-between releases into the next stepping stone, always tagged with the version that introduced them (e.g. Added in 14). So Java 17 also covers the good stuff from 12–16, Java 21 covers 18–20, and Java 25 covers 22–24. This page is updated to cover each new release as it ships — currently through Java 26.

Release timeline

March 2014 · LTS
Java 8
Lambdas, Streams, default/static interface methods, method references, Optional, the new java.time API, CompletableFuture — the modern Java baseline.
Sept 2017
Java 9
Modules (JPMS), JShell, collection factory methods, reactive Flow, HTTP/2 client (incubator).
Sept 2018 · LTS
Java 11 covers 10
var (from 10), standard HttpClient, run single-file source, new String/Files methods.
Sept 2021 · LTS
Java 17 covers 12–16
Records, sealed classes, switch expressions, text blocks, pattern matching for instanceof, helpful NPEs.
Sept 2023 · LTS
Java 21 covers 18–20
Virtual threads, pattern matching for switch, record patterns, sequenced collections.
Sept 2025 · LTS
Java 25 covers 22–24
Scoped values (final), stream gatherers, FFM API (final), compact source files & instance main, module import declarations.
March 2026
Java 26
HTTP/3 client, AOT object caching, lazy/stable constants, structured concurrency & primitive patterns advance.
