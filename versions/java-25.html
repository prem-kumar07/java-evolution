September 2025 · LTS

Java 25 LTS

The current LTS. A wave of features graduated to final: scoped values, stream gatherers, the Foreign Function & Memory API, compact source files & instance main, flexible constructor bodies and module import declarations — plus real startup wins from Project Leyden.

Folded in: features from 22 23 24 are included and tagged.
⚠ Migration watch-outs (21 → 25).
  • Security Manager permanently disabled 24 — System.setSecurityManager now throws. Any code still using it must be reworked.
  • sun.misc.Unsafe memory-access methods warn and are being removed — migrate to the FFM API / VarHandle.
  • 32-bit x86 port removed — no more 32-bit Linux/Windows JDK builds.
  • Compact object headers change object sizes — tools that assume the old header layout may need updating (opt-in on 24, default-capable on 25).
  • Upside: virtual threads no longer pin on synchronized — safe to drop the 21-era ReentrantLock workarounds.

1 · Language features

Compact source files & instance main Final in 25

You can now write a runnable program with no class, no public static, no explicit imports of java.base, and a simple IO helper. The full ceremony is still there when you need it — this just removes it for small programs and learners.

Before
public class Hello {
  public static void main(String[] args) {
    System.out.println("Hello, world");
  }
}
After (Java 25)
void main() {
  IO.println("Hello, world");
}
// java Hello.java — no class, no static, IO built in

Flexible constructor bodies Final in 25

Run validation/normalisation statements before calling super(...) or this(...) — previously impossible.

Before — validate after super, or in a helper
Range(int lo, int hi) {
  super();                 // must be first
  if (lo > hi)             // validation too late
    throw new IllegalArgumentException();
  this.lo = lo; this.hi = hi;
}
After (Java 25)
Range(int lo, int hi) {
  if (lo > hi)             // guard BEFORE super()
    throw new IllegalArgumentException();
  super();
  this.lo = lo; this.hi = hi;
}

Module import declarations Final in 25

Import every package a module exports in one line — handy in scripts and prototypes.

Before
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;
import java.util.function.Function;
After (Java 25)
import module java.base;   // all java.base exports at once

Scoped values Final in 25

An immutable, safer replacement for ThreadLocal, designed for virtual threads.

final static ScopedValue<User> CURRENT = ScopedValue.newInstance();

ScopedValue.where(CURRENT, user).run(() -> handleRequest());
// deeper in the call stack:
User u = CURRENT.get();   // bound for this scope only, cannot be mutated

2 · New & updated APIs

Stream Gatherers Final in 24

Custom intermediate operations — the missing counterpart to custom Collectors.

Before — no clean windowing
// sliding windows of 3: manual index loops
List<List<Integer>> windows = new ArrayList<>();
for (int i = 0; i + 3 <= xs.size(); i++)
  windows.add(xs.subList(i, i + 3));
After — Gatherers
var windows = xs.stream()
    .gather(Gatherers.windowSliding(3))
    .toList();
// also: fold, scan, mapConcurrent, windowFixed

Writing your own gatherer → Streams & Gatherers deep-dive.

Foreign Function & Memory API Final in 22

Call native libraries and manage off-heap memory with pure Java — the modern, safe replacement for JNI. → FFM deep-dive.

3 · Tooling

  • Launch multi-file source programs Added in 22 — java Main.java compiles referenced sibling files on demand (no build tool). See Quick start.
  • Markdown in Javadoc Added in 23 — write doc comments as Markdown (/// ...) instead of HTML tags.
  • Project Leyden — faster startup: Ahead-of-Time Class Loading & Linking Added in 24, plus AOT command-line ergonomics and AOT method profiling Added in 25 shift work from run time to a training/build step.
  • JFR upgrades 25 — CPU-time profiling (experimental), cooperative sampling, method timing & tracing.

4 · JVM / performance / other

  • Compact Object Headers Final in 25 (experimental in 24) — shrinks every object's header from 12/16 to 8 bytes, meaningfully cutting heap use.
  • Virtual threads no longer pinned on synchronized Added in 24 — a major reliability fix; blocking inside a synchronized block no longer ties up a carrier thread.
  • Generational Shenandoah 25 and ZGC generational by default 23 / non-generational mode removed 24.
  • 32-bit x86 port removed; sun.misc.Unsafe memory-access methods now warn.

5 · Summary cheat-sheet

Java 25 (LTS) in one glance

  • Simpler programs: void main() + IO.println, import module java.base
  • Final: scoped values, stream gatherers (24), FFM (22), flexible constructors, unnamed _ (22)
  • Crypto: KDF API, ML-KEM / ML-DSA (post-quantum)
  • Startup: Project Leyden AOT caching
  • Memory: compact object headers
  • Reliability: virtual threads no longer pin on synchronized
  • Preview: primitive patterns, structured concurrency, stable values
