The current LTS. A wave of features graduated to final: scoped values, stream gatherers, the Foreign Function & Memory API, compact source files & instance main, flexible constructor bodies and module import declarations — plus real startup wins from Project Leyden.

1 · Language features

Compact source files & instance main Final in 25 JEP 512

Why it matters: a runnable program with no class, no public static, no explicit java.base imports, and a simple IO helper — much gentler for learners and scripts. The full ceremony is still available when you need it.

Before
public class Hello {
  public static void main(String[] args) {
    System.out.println("Hello, world");
  }
}
After (Java 25)
void main() {
  IO.println("Hello, world");
}
// java Hello.java — no class, no static, IO built in

Flexible constructor bodies Final in 25 JEP 513

Why it matters: validate or normalise arguments before calling super(...)/this(...) — previously impossible, forcing awkward workarounds.

Before — validation must come after super()
Range(int lo, int hi) {
  super();                 // must be first statement
  if (lo > hi)             // too late — super already ran
    throw new IllegalArgumentException();
  this.lo = lo; this.hi = hi;
}
After (Java 25)
Range(int lo, int hi) {
  if (lo > hi)             // guard BEFORE super()
    throw new IllegalArgumentException();
  super();
  this.lo = lo; this.hi = hi;
}

Module import declarations Final in 25 JEP 511

Why it matters: import every package a module exports in one line — great for scripts and prototypes.

Before
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;
import java.util.function.Function;
After (Java 25)
import module java.base;   // all java.base exports at once

Unnamed variables & patterns Final in 22

Before — name things you never use
try { ... }
catch (IOException ignored) { retry(); }
for (Order o : orders) count++;   // 'o' unused
After (Java 22)
try { ... }
catch (IOException _) { retry(); }
for (var _ : orders) count++;
if (p instanceof Point(int x, _)) use(x);   // ignore y

Scoped values Final in 25 JEP 506

Why it matters: an immutable, auto-cleaning replacement for ThreadLocal, designed for virtual threads.

Before — ThreadLocal, must remove()
CURRENT.set(user);
try { handle(); }
finally { CURRENT.remove(); }   // leak if forgotten
After (Java 25)
ScopedValue.where(CURRENT, user).run(() -> handle());
// auto-unbound; deeper code reads CURRENT.get()

Full story → Scoped values deep-dive.

Still previewing in 25

  • Primitive types in patterns Preview — case int i, etc.
  • Structured concurrency Preview (5th) → deep-dive.

    Note (Java 26): The Joiner API introduced here was refined in Java 26 to include an onTimeout() hook, change allSuccessfulOrThrow() to return a List<T> instead of a Stream, and rename the "any" joiner to anySuccessfulOrThrow().

  • Stable Values Preview — write-once, lazy, thread-safe constants: 
    StableValue<Logger> logger = StableValue.of();
Logger l = logger.orElseSet(() -> createLogger());   // computed at most once

    Note (Java 26): StableValue was renamed to LazyConstant in Java 26 (second preview). Code targeting Java 25 preview uses StableValue; Java 26 uses LazyConstant.

2 · New & updated APIs

Stream Gatherers Final in 24 JEP 485

Why it matters: custom intermediate operations — the missing counterpart to a custom Collector.

Before — manual windowing
List<List<Integer>> windows = new ArrayList<>();
for (int i = 0; i + 3 <= xs.size(); i++)
  windows.add(xs.subList(i, i + 3));
After — Gatherers
var windows = xs.stream()
    .gather(Gatherers.windowSliding(3))
    .toList();
// also: fold, scan, mapConcurrent, windowFixed

Writing your own gatherer → Streams & Gatherers deep-dive.

Foreign Function & Memory API Final in 22 JEP 454

Why it matters: call native libraries and manage off-heap memory in pure Java — the safe, supported replacement for JNI.

// call C's strlen() — no C glue code, no build step
Linker linker = Linker.nativeLinker();
MethodHandle strlen = linker.downcallHandle(
    linker.defaultLookup().find("strlen").orElseThrow(),
    FunctionDescriptor.of(ValueLayout.JAVA_LONG, ValueLayout.ADDRESS));

try (Arena arena = Arena.ofConfined()) {
  MemorySegment cString = arena.allocateFrom("hello");
  long len = (long) strlen.invoke(cString);   // -> 5
}

A complete, runnable program (off-heap memory + downcall + upcall) → FFM deep-dive.

Cryptography

Why it matters: the Key Derivation Function API gives HKDF (and future algorithms) a standard, uniform API — before 25, teams either hand-rolled HKDF from javax.crypto.Mac (easy to get subtly wrong) or pulled in a third-party crypto library just for this.

Before — hand-rolled HKDF via Mac
// HKDF-Extract, manually, using HMAC — easy to get wrong
Mac hmac = Mac.getInstance("HmacSHA256");
hmac.init(new SecretKeySpec(salt, "HmacSHA256"));
byte[] prk = hmac.doFinal(initialKeyMaterial);
// ...then a hand-written HKDF-Expand loop with a counter byte,
// concatenating info + counter + previous block each round
After (Java 25) — one standard API
KDF hkdf = KDF.getInstance("HKDF-SHA256");
AlgorithmParameterSpec params = HKDFParameterSpec.ofExtract()
    .addIKM(initialKeyMaterial)
    .addSalt(salt).thenExpand(info, 32);

SecretKey key = hkdf.deriveKey("AES", params);   // a 32-byte AES key
// verified: derives a correct 32-byte key in one call
// Quantum-resistant algorithms (Added in 24) — see the KEM walkthrough on the Java 21 page
KeyPairGenerator kem = KeyPairGenerator.getInstance("ML-KEM");   // JEP 496
Signature       dsa = Signature.getInstance("ML-DSA");          // JEP 497

3 · Tooling

Markdown in Javadoc Added in 23

Why it matters: write doc comments in Markdown (/// lines) instead of HTML tags.

Before — HTML tags
/**
 * Returns the <b>sum</b>.
 * <ul><li>fast</li><li>null-safe</li></ul>
 * @param xs the values
 */
After (Java 23)
/// Returns the **sum**.
/// - fast
/// - null-safe
/// @param xs the values
  • Launch multi-file source programs Added in 22 — java Main.java also compiles any sibling .java files it references, on demand — no build tool, no manifest, for small multi-class programs: 
    // Main.java
void main() {
  IO.println(Greeter.greet("world"));
}

// Greeter.java (same directory)
class Greeter {
  static String greet(String name) { return "Hello, " + name; }
}

// java Main.java   — compiles BOTH files and runs, in one step
    See Quick start for single-file launch too.
  • Project Leyden — faster startup: AOT Class Loading & Linking 24, plus AOT command-line ergonomics & method profiling 25 shift work from run time to a training/build step. Full walkthrough with verified before/after timing → AOT Cache deep-dive.
  • JFR upgrades 25 — CPU-time profiling, cooperative sampling, method timing & tracing.

4 · JVM / performance / other

  • Compact Object Headers Final in 25 (experimental in 24) — shrinks every object header from 12/16 to 8 bytes, meaningfully cutting heap use.
  • Virtual threads no longer pinned on synchronized Added in 24 — a major reliability fix.
  • Generational Shenandoah 25; ZGC generational by default 23 / non-generational removed 24.
  • 32-bit x86 port removed; sun.misc.Unsafe memory-access methods warn.

5 · Summary cheat-sheet

Java 25 (LTS) in one glance

  • Simpler programs: void main() + IO.println, import module java.base
  • Final: scoped values, stream gatherers (24), FFM (22), flexible constructors, unnamed _ (22)
  • Crypto: KDF API, ML-KEM / ML-DSA (post-quantum)
  • Javadoc: Markdown comments (23); startup: Project Leyden AOT
  • Memory: compact object headers; reliability: VTs no longer pin
  • Preview: primitive patterns, structured concurrency, stable values
