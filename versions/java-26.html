March 2026

Java 26

A feature release that pushes performance and platform integrity forward: HTTP/3 in the HTTP client, more AOT startup caching, a faster G1, and the "final means final" integrity work — while structured concurrency and primitive patterns edge closer to final.

Non-LTS. Java 26 is a 6-month feature release. Production teams on LTS should track these as previews of what's coming; the next LTS will consolidate them.

1 · Language features

Prepare to Make final Mean Final JEP 500

Part of the "integrity by default" effort. Historically, libraries could mutate final fields via deep reflection (setAccessible). Java 26 begins warning on this so a future release can enforce that final truly is final — enabling constant-folding optimisations and safer code.

Before — silently allowed
Field f = obj.getClass().getDeclaredField("id");
f.setAccessible(true);
f.setInt(obj, 999);      // mutates a final field — worked
After (Java 26)
// same code now emits a warning; a future release
// will throw. Opt back in per-module only if needed:
//   --enable-final-field-mutation=<module>

Primitive types in patterns, instanceof & switch Preview (4th)

Extends pattern matching to primitives, with exactness checks that replace error-prone casts.

Object o = 42;
switch (o) {
  case int i    -> System.out.println("int " + i);
  case double d -> System.out.println("double " + d);
  default       -> {}
}
// and safe range checks:
if (bigValue instanceof int i) { ... }   // only matches if it fits in int

Structured concurrency Preview (6th)

Approaching final. Run a group of subtasks as one unit with automatic cancellation/joining → deep-dive.

2 · New & updated APIs

HTTP/3 for the HTTP Client JEP 517

The java.net.http.HttpClient (from Java 11) now speaks HTTP/3 (QUIC over UDP) — lower latency and better behaviour on lossy networks.

Before — HTTP/1.1 or /2
HttpClient client = HttpClient.newBuilder()
    .version(HttpClient.Version.HTTP_2)
    .build();
After (Java 26)
HttpClient client = HttpClient.newBuilder()
    .version(HttpClient.Version.HTTP_3)
    .build();
// same request/response API — only the transport changes

Lazy Constants Preview (2nd)

The feature previewed as "Stable Values" in Java 25, now renamed. A safe primitive for compute-once, thread-safe lazy initialisation that the JIT can treat like a constant.

// preview API shape
LazyConstant<Config> config = LazyConstant.of(() -> loadConfig());
Config c = config.get();   // loadConfig() runs at most once, then folded as a constant

Also previewing / incubating

  • PEM encodings of cryptographic objects Preview (2nd) — read/write keys & certificates in PEM text directly.
  • Vector API 11th incubator — SIMD math; still incubating pending Project Valhalla.

3 · Tooling

  • Ahead-of-Time Object Caching with Any GC JEP 516 — Project Leyden's AOT cache (warmed classes/objects) now works regardless of the selected garbage collector, widening who can benefit from faster startup.

4 · JVM / performance / other

  • G1: improved throughput by reducing synchronization JEP 522 — less overhead in the default collector.
  • Applet API removed Removed — the last of the applet era is gone (deprecated back in 17).

5 · Summary cheat-sheet

Java 26 in one glance

  • HTTP/3: .version(HttpClient.Version.HTTP_3)
  • Integrity: "final means final" — deep reflection on final fields warns
  • Startup: AOT object caching with any GC
  • Perf: faster G1; Applet API removed
  • Preview: primitive patterns (4th), structured concurrency (6th), lazy constants (2nd)
